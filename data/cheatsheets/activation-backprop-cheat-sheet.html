Vanishing Gradient Problem
📡 Imagine passing a whisper through 100 people. By the time it reaches the end, the message is nearly inaudible. Sigmoid squashes all values into (0,1), and its gradients are tiny — multiplying tiny numbers through 100 layers makes the gradient vanish near 0. Early layers stop learning.
⚠️ Sigmoid/Tanh cause vanishing gradients in deep networks Their derivatives max out at 0.25 (sigmoid) and 1.0 (tanh). In a 10-layer network, the gradient shrinks to nearly 0 by the time it reaches layer 1. Fix: use ReLU for hidden layers — its gradient is either 0 or 1, no shrinking.
Backpropagation
🔙 Backprop is how the network learns from its mistakes. Forward pass = make a prediction. Compute loss = measure how wrong. Backward pass = trace which weights caused the error, compute their gradients. Optimizer step = nudge each weight to reduce the error.
The 5-Step Learning Cycle
1
Forward pass — data flows through layers, producing a prediction
2
Compute loss — measure how far prediction is from truth
3
Backward pass — chain rule traces gradient of loss back through every weight
4
Gradient stored — each weight gets .grad populated
5
Optimizer step — subtract gradient × learning rate from each weight
PyTorch autograd — How It Works
import torch

# requires_grad=True → PyTorch tracks operations
x = torch.tensor([2.0], requires_grad=True)
w = torch.tensor([3.0], requires_grad=True)

# Forward pass
y = x * w + 1   # y = 2*3 + 1 = 7
loss = (y - 5) ** 2  # loss = (7-5)² = 4

# Backward pass — compute all gradients
loss.backward()

print(w.grad)  # d(loss)/d(w) = 2*(y-5)*x = 2*2*2 = 8
print(x.grad)  # d(loss)/d(x) = 2*(y-5)*w = 2*2*3 = 12

# Update weight manually (what optimizer does)
with torch.no_grad():
    w -= 0.01 * w.grad   # lr=0.01
    w.grad.zero_()       # clear for next step
💡 zero_grad() — why it matters PyTorch accumulates (adds) gradients by default. If you forget optimizer.zero_grad() before each backward pass, gradients from the previous step add to the current ones — making weight updates wrong. Always zero gradients first.
Chain Rule — The Math Behind Backprop
🔗 The chain rule says: if y depends on x through z, then dy/dx = dy/dz × dz/dx. Backprop applies this rule layer by layer — multiplying gradients from output back to input to find how each weight affects the final loss.

For a network: loss → output layer → hidden layer → input

Gradient at each layer = (gradient from next layer) × (local gradient of this layer's operation)

# Chain rule in action — manual example
# Network: x → h = relu(wx) → loss = (h-y)²

# Given:
# w=2, x=3, y=5
# h = relu(2*3) = 6
# loss = (6-5)² = 1

# d(loss)/d(h)  = 2*(h-y)    = 2*(6-5) = 2
# d(h)/d(wx)   = relu_grad  = 1 (since h>0)
# d(wx)/d(w)   = x           = 3

# Chain rule: d(loss)/d(w)
# = d(loss)/d(h) × d(h)/d(wx) × d(wx)/d(w)
# = 2 × 1 × 3 = 6
# → w updates by: w -= lr × 6
Gradient Clipping — Exploding Gradients
# Opposite problem to vanishing:
# gradients grow exponentially in deep/RNN nets
# loss = NaN is the symptom

import torch.nn as nn

loss.backward()

# Clip gradient norm to max 1.0
nn.utils.clip_grad_norm_(
    model.parameters(), max_norm=1.0
)

optimizer.step()
# No more exploding gradients
Master Interview Answers
🎤 Q: "Explain backpropagation in plain English."
Backpropagation computes how much each weight contributed to the final error by applying the chain rule from the output layer back to the input. It gives every weight a gradient — a number saying "if you increase this weight slightly, the loss goes up or down by this much." The optimizer then adjusts each weight in the direction that reduces the loss. PyTorch's autograd does this automatically when you call loss.backward().
🎤 Q: "What is the vanishing gradient problem?"
In deep networks using sigmoid or tanh activations, gradients get multiplied together as they flow backward. Since sigmoid's maximum gradient is 0.25, multiplying it through 10 layers gives 0.25^10 ≈ 0.000001 — effectively zero. The earliest layers receive almost no gradient signal and stop learning. ReLU solves this because its gradient is either 0 or 1, so it doesn't shrink gradients during backprop.
✅ One-line summary ReLU for hidden layers — avoids vanishing gradient. Sigmoid/Softmax for output only. Backprop = chain rule applied backwards through layers, computing d(loss)/d(weight) for every weight. zero_grad() before every backward pass. Clip gradients for RNNs/very deep nets.
