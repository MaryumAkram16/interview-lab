Epochs, Iterations, Batch Size
📖 Imagine studying a 1000-page textbook. One epoch = reading all 1000 pages once. Batch size = how many pages you study before pausing to review. Iteration = number of pauses. More epochs = more passes through the whole book.

Epoch = one complete pass through the entire training dataset.

Batch size = number of samples processed before weights are updated.

Iteration = one weight update step = dataset_size ÷ batch_size per epoch.

The Math
# Example: 10,000 samples, batch_size=100
# Iterations per epoch = 10,000 / 100 = 100
# If you run 50 epochs:
# Total iterations = 50 × 100 = 5,000 weight updates
Batch Size Tradeoffs
Batch SizeTypeProCon

💡 Rule of thumb for batch size Start with 32 or 64. Larger batches train faster but may generalise worse. Smaller batches act as regularization — the noise in gradient estimates helps escape sharp local minima.

Loss Functions Deep Dive
📏 A loss function is the scorecard that tells the model how wrong it is. The model's entire job is to minimise this number. Different tasks need different scorecards.
Classification Loss
import torch.nn as nn
import torch

# Binary Cross-Entropy — binary classification
# Output: sigmoid probability 0–1
bce = nn.BCELoss()
y_pred = torch.tensor([0.9, 0.2, 0.8])
y_true = torch.tensor([1.0, 0.0, 1.0])
loss = bce(y_pred, y_true)

# CrossEntropyLoss — multi-class
# Takes raw logits (no softmax needed!)
ce = nn.CrossEntropyLoss()
logits = torch.tensor([[2.0, 0.5, 0.3],
                         [0.1, 3.2, 0.4]])
labels = torch.tensor([0, 1])   # class indices
loss = ce(logits, labels)
Regression Loss
# MSE Loss — mean squared error
# Penalises large errors heavily
mse = nn.MSELoss()
y_pred = torch.tensor([2.5, 0.3, 1.8])
y_true = torch.tensor([3.0, 0.0, 2.0])
loss = mse(y_pred, y_true)

# L1 Loss — mean absolute error
# More robust to outliers than MSE
l1 = nn.L1Loss()
loss = l1(y_pred, y_true)

# Huber Loss — best of MSE + L1
# MSE for small errors, L1 for large outliers
huber = nn.HuberLoss()
loss = huber(y_pred, y_true)

Master Interview Answers
🎤 Q: "What is the difference between an epoch, a batch, and an iteration?"
An epoch is one complete pass through the entire training dataset. A batch is the number of samples processed before the model's weights are updated once. An iteration is one weight update — so if you have 1000 samples and batch size 100, you have 10 iterations per epoch. You typically run many epochs until the loss converges.
🎤 Q: "Why use CrossEntropyLoss for classification and MSELoss for regression?"
CrossEntropyLoss is designed for probability distributions — it measures how far the predicted class probabilities are from the true one-hot labels, and it pairs naturally with softmax output. MSELoss measures the squared difference between predicted and actual numbers, which is the right penalty for continuous output. Using MSELoss for classification would treat class labels as numbers and create a false ordering between classes.
✅ One-line summary Epoch = full data pass. Batch = samples per update. Iteration = updates per epoch = data_size/batch_size. CrossEntropyLoss for classification (takes raw logits). MSELoss for regression. Adam is the default optimizer. Learning rate is the most critical hyperparameter — start at 1e-3.
