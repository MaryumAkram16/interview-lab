Diagnosing with Learning Curves
from sklearn.model_selection import learning_curve
import numpy as np

train_sizes, train_scores, val_scores = learning_curve(
    model, X, y, cv=5,
    train_sizes=np.linspace(0.1, 1.0, 10)
)

# Diagnosis:
# Both curves high error → underfitting (bias)
# Large gap between train/val → overfitting (variance)
# Curves converge at low error → good fit
⚠️ The classic overfitting signal Training accuracy = 99%, validation accuracy = 65%. The model memorised the training data and cannot generalise. This gap between train and val performance IS overfitting. Fix it with regularization, dropout, or more data.
Fixes for Overfitting
1 — Regularization (L1 and L2)
⚖️ Regularization adds a penalty for complexity — it discourages the model from assigning huge weights to any one feature. Like telling a student: "don't rely on memorising one trick — learn the general concept."
from sklearn.linear_model import Ridge, Lasso

# L2 Regularization — Ridge
# Penalty = alpha × sum(weights²)
# Shrinks all weights, none to zero
ridge = Ridge(alpha=1.0)
ridge.fit(X_train, y_train)

# L1 Regularization — Lasso
# Penalty = alpha × sum(|weights|)
# Drives irrelevant feature weights to zero
# Automatic feature selection!
lasso = Lasso(alpha=0.1)
lasso.fit(X_train, y_train)

2 — Dropout (Neural Networks)
import torch.nn as nn

# Randomly zero out 20% of neurons each pass
# Forces network to learn redundant representations
model = nn.Sequential(
    nn.Linear(128, 64),
    nn.ReLU(),
    nn.Dropout(p=0.2),   # 20% dropout
    nn.Linear(64, 10)
)

✅ Other overfitting fixes Get more training data (most effective). Data augmentation (flip/rotate images). Reduce model complexity (fewer layers/neurons). Ensemble methods (Random Forest averages many trees).
Cross-Validation
🔄 k-Fold CV is like taking 5 different exams from the same material. Each time, a different portion of data is the test set. Average all 5 scores for a reliable estimate of how well the model truly generalises.
k-Fold Cross-Validation
from sklearn.model_selection import cross_val_score
from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier(n_estimators=100)

# 5-fold CV — splits data into 5 chunks
# trains on 4, tests on 1, rotates 5 times
scores = cross_val_score(
    model, X, y,
    cv=5,            # 5 folds
    scoring='accuracy'
)

print(scores)
# [0.91, 0.89, 0.93, 0.88, 0.92]

print(f"Mean: {scores.mean():.3f}")
# Mean: 0.906
print(f"Std:  {scores.std():.3f}")
# Std: 0.018 — low = consistent model

Master Interview Answers
🎤 Q: "What is overfitting and how do you fix it?"
Overfitting is when a model performs well on training data but poorly on new data — it has memorised noise instead of learning patterns. The signal is a large gap between training accuracy and validation accuracy. Fixes include regularization (L1/L2), dropout for neural networks, early stopping, reducing model complexity, and getting more training data. The best fix depends on why the model is overfitting.
🎤 Q: "What is cross-validation and why is it better than a single train/test split?"
Cross-validation trains and evaluates the model multiple times on different subsets of the data. In 5-fold CV, the data is split into 5 chunks — the model trains on 4 and tests on 1, repeating 5 times. The average score is much more reliable than a single split, which can be lucky or unlucky depending on which data ended up in the test set. CV also uses all data for both training and validation.
✅ One-line summary Underfitting = high bias, too simple, both errors high. Overfitting = high variance, memorised training data, gap between train/val. Fix overfitting: L1/L2 regularization, dropout, early stopping, more data. Cross-validation = rotate test fold k times, average scores for reliable evaluation.
