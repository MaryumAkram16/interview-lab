What is Hashing?
📦 Analogy: A hash function is like a post office sorting machine. You give it a letter (your data), it spits out a slot number (the hash), and that is exactly where the letter goes. Finding it later is instant — no need to check every slot.

A hash function takes an input (a key) and returns a fixed-size number called a hash code. That number is used as an index to store the value in an array called a hash table.

⚠️ When does worst case O(n) happen? When all keys hash to the same slot — called a collision storm. A good hash function makes this almost impossible.
What Makes a Good Hash Function?

Three rules every good hash function follows:

1. Deterministic — same input always gives same output.

2. Uniform distribution — spreads keys evenly across all slots. No clustering.

3. Fast to compute — O(1) or close to it.

🎤 Q: "What is a hash function?"
A hash function takes a key and returns a fixed number used as an array index. It lets us store and retrieve values in O(1) time instead of O(n). Python's dictionary uses hashing internally — every time you do dict[key], Python hashes the key and jumps directly to the right memory slot.
Collision Handling
🚗 Analogy: Two cars booked the same parking spot. A collision happens when two different keys produce the same hash index. You need a strategy to handle it.

A collision occurs when hash(key1) == hash(key2) but key1 != key2. Two main strategies to fix it:

Strategy 1 — Chaining (Linked List at each slot)

Each slot holds a list. When two keys collide, both go into the list at that slot.

# Chaining — each bucket is a list
table = [[] for _ in range(10)]

def insert(key, value):
    index = hash(key) % 10
    # Check if key already exists → update
    for i, (k, v) in enumerate(table[index]):
        if k == key:
            table[index][i] = (key, value)
            return
    # Otherwise append new pair
    table[index].append((key, value))

def search(key):
    index = hash(key) % 10
    for k, v in table[index]:
        if k == key: return v
    return None
✅ Chaining Pros Simple to implement. Works well even when load factor exceeds 1. Python's dict uses a variant of this.
Strategy 2 — Open Addressing (Linear Probing)

No lists. If slot is taken, move to the next empty slot.

# Linear Probing — find next empty slot
SIZE = 10
table = [None] * SIZE

def insert_probe(key, value):
    index = hash(key) % SIZE
    while table[index] is not None:
        if table[index][0] == key:  # update
            break
        index = (index + 1) % SIZE  # probe
    table[index] = (key, value)
⚠️ Open Addressing weakness: Clustering Keys bunch up near collision points, making future lookups slow. Quadratic probing or double hashing reduces this.

🎤 Q: "What happens when two keys hash to the same index?"
That is called a collision. There are two main ways to handle it. Chaining stores multiple key-value pairs in a list at the same slot — simple and handles high load. Open addressing finds the next empty slot instead — more cache-efficient but struggles when the table gets too full.
Real-World Hash Applications
Load Factor — When to Resize
🏠 Analogy: Load factor is how full the house is. Too many people in too few rooms = collisions everywhere. Time to move to a bigger house (resize).

Load factor = number of entries ÷ number of slots

When load factor exceeds ~0.7, the hash table resizes (doubles in size) and rehashes all existing keys.

Master Interview Answers
🎤 Q: "What is a hash map and when would you use it?"
A hash map stores key-value pairs and gives O(1) average time for insert, search, and delete. I use it when I need fast lookups by key — like storing processed request IDs to prevent duplicate payments, or caching API responses by request hash. Python's dict is a hash map.
🎤 Q: "What is the time complexity of hash map operations?"
O(1) average for insert, search, and delete. Worst case is O(n) but only when all keys collide at the same slot — which a good hash function prevents. In practice, Python dict is effectively O(1).
🎤 Q: "How does Python's dictionary handle collisions?"
Python uses open addressing with a technique called perturbation-based probing — not simple linear probing. When a collision occurs, it computes a new slot using both the hash and the existing collision pattern, which reduces clustering. The dict also resizes automatically when the load factor crosses about 66%.
✅ One-line summary to memorize Hash map = instant lookup by key using a hash function to turn the key into an array index. O(1) average. Collisions handled by chaining (lists) or open addressing (probing). Python dict is a hash map.
