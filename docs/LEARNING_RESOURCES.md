# Resource research notes

Checked 15 November 2026 against the providers’ public sites and documentation. This is a curated selection for Maryum’s interview gaps, not a universal ranking. Descriptions are original short summaries; course material is linked, not copied.

Prioritise written lessons and notebooks where available. NeetCode and LangChain Academy are explicitly marked as mixed/video resources. Paid upgrades and possible exercise/API costs are called out. External course progress is not synchronized with this workspace.

## LeetCode Problems

Topic: Coding & Python

Interview-style algorithm problems with an online editor and test cases. Free problems are available; Premium unlocks additional questions and features. An account is useful for submissions.

Provider sources:

- https://leetcode.com/problemset/
- https://support.leetcode.com/hc/en-us/articles/360011884094-What-will-I-get-with-a-premium-subscription

## NeetCode Roadmap

Topic: Coding & Python

A structured route through coding-interview patterns, including Arrays & Hashing. The roadmap and practice lists have free content; Pro courses and features are separate.

Provider sources:

- https://neetcode.io/roadmap
- https://blog.neetcode.io/p/prepare-coding-interviews

## Python Track

Topic: Coding & Python

Python exercises focused on language concepts, readable solutions, and test-driven practice. Free Python track. An account is needed to save work and use track features.

Provider sources:

- https://exercism.org/tracks/python

## Python Challenges

Topic: Coding & Python

Small Python challenges covering strings, sets, collections, classes, and debugging. Sign-in may be needed to submit and save challenge progress.

Provider sources:

- https://www.hackerrank.com/domains/python

## Machine Learning Crash Course

Topic: Machine Learning

Modular explanations and exercises for regression, classification, data, and model evaluation. Public learning material. Some exercises use a notebook environment.

Provider sources:

- https://developers.google.com/machine-learning/crash-course

## Intro to Machine Learning

Topic: Machine Learning

An applied introduction to building and validating a first machine-learning model. Kaggle Learn is free; an account may be required for interactive exercises.

Provider sources:

- https://www.kaggle.com/learn/intro-to-machine-learning
- https://www.kaggle.com/learn/intro-to-machine-learning/exercises

## Machine Learning in Python

Topic: Machine Learning

A careful introduction to predictive pipelines, preprocessing, cross-validation, and interpreting results. Public lessons and notebooks. The hosted MOOC has optional enrollment for additional course features.

Provider sources:

- https://inria.github.io/scikit-learn-mooc/

## Learn the Basics

Topic: Deep Learning

Official tutorials following a complete workflow: tensors, datasets, models, autograd, and optimization. Tutorials are free. You can run examples locally or through supported notebook links.

Provider sources:

- https://docs.pytorch.org/tutorials/beginner/basics/intro.html

## Dive into Deep Learning

Topic: Deep Learning

A mathematical, code-based textbook covering neural networks, optimization, attention, and transformers. Free online book and code. Local or cloud computing is needed to run exercises.

Provider sources:

- https://d2l.ai/

## Deep Learning for Coders — Online Book

Topic: Deep Learning

The fast.ai book links its explanations to notebooks you can read and run. The online book is free; print editions and optional cloud compute may cost money.

Provider sources:

- https://course.fast.ai/Resources/book.html

## LLM Course

Topic: Generative AI & Agents

Learn transformers, tokenizers, datasets, model inference, and fine-tuning through the Hugging Face ecosystem. The course is free. Accounts or computing resources may be needed for hands-on activities.

Provider sources:

- https://huggingface.co/learn/llm-course/en/chapter1/1

## AI Agents Course

Topic: Generative AI & Agents

Agent foundations, tools, frameworks, agentic RAG, and evaluation with practical assignments. Course material is free. A free Hugging Face account supports hands-on activities; external compute/API usage can vary.

Provider sources:

- https://huggingface.co/learn/agents-course/unit0/introduction

## Generative AI for Beginners

Topic: Generative AI & Agents

Open learning material for building generative-AI applications with practical examples. Lessons are free to read. Running examples can require provider accounts and incur model/API charges.

Provider sources:

- https://github.com/microsoft/generative-ai-for-beginners

## Introduction to LangGraph — Python

Topic: Generative AI & Agents

Learn graph-based agent workflows, state, memory, and human-in-the-loop patterns. The course is free; registration may be required. Model calls and optional hosted services can have separate costs.

Provider sources:

- https://academy.langchain.com/courses/intro-to-langgraph
- https://academy.langchain.com/

## Interactive SQL Lessons

Topic: Backend & SQL

Short interactive lessons for SELECT, filtering, joins, aggregation, and data modification. Public lessons and in-browser exercises.

Provider sources:

- https://sqlbolt.com/

## FastAPI Tutorial — User Guide

Topic: Backend & SQL

Official examples for request validation, response codes, authentication, databases, and testing. Documentation is free. Run the sample API locally with Codex or Claude Code.

Provider sources:

- https://fastapi.tiangolo.com/tutorial/
