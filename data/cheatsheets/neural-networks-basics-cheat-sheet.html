How a Neuron Works
🧠 A single neuron is like a voting machine. It takes multiple inputs, weighs each vote by importance (weights), adds a baseline vote (bias), then decides whether to fire based on an activation function. Many neurons together = a network.

Each neuron computes: output = activation(w₁x₁ + w₂x₂ + ... + b)

Where w = weights (learned), x = inputs, b = bias, activation = non-linear function.

Layer Types
LayerRole
Input LayerReceives raw features (no computation)
Hidden LayersLearn intermediate representations
Output LayerFinal prediction — size = number of classes
Activation Functions
FunctionOutput RangeUse When
ReLU[0, ∞)Hidden layers — default choice
Sigmoid(0, 1)Binary classification output
Softmax(0,1) sums to 1Multi-class output layer
Tanh(-1, 1)Hidden layers (centred)
LeakyReLU(-∞, ∞)Avoid dying ReLU problem
⚠️ The Dying ReLU Problem ReLU outputs 0 for all negative inputs. If a neuron always receives negative inputs, its gradient is always 0 — it never learns. Fix: use LeakyReLU which allows a tiny gradient for negative values instead of hard zero.
Why Activation Functions Are Needed
📐 Without activation functions, stacking many linear layers still produces a single linear function — no matter how deep your network is. Activation functions introduce non-linearity, allowing the network to learn complex, curved decision boundaries.
PyTorch — Build a Network
Sequential Model
import torch
import torch.nn as nn

# Simple feedforward network
# Input: 10 features → Hidden: 64 → Output: 3 classes
model = nn.Sequential(
    nn.Linear(10, 64),    # input → hidden
    nn.ReLU(),             # activation
    nn.Dropout(p=0.3),    # regularization
    nn.Linear(64, 32),    # hidden → hidden
    nn.ReLU(),
    nn.Linear(32, 3),     # hidden → output
    nn.Softmax(dim=-1)    # multi-class output
)
Custom nn.Module Class
class TriageNet(nn.Module):
    """MediLens triage classifier"""
    def __init__(self, input_dim, num_classes):
        super().__init__()
        self.fc1 = nn.Linear(input_dim, 128)
        self.fc2 = nn.Linear(128, 64)
        self.fc3 = nn.Linear(64, num_classes)
        self.relu    = nn.ReLU()
        self.dropout = nn.Dropout(p=0.2)

    def forward(self, x):
        # Forward pass — data flows through layers
        x = self.relu(self.fc1(x))
        x = self.dropout(x)
        x = self.relu(self.fc2(x))
        x = self.fc3(x)   # raw logits, no activation
        return x

# Create model
model = TriageNet(input_dim=20, num_classes=4)
print(model)

💡 nn.Module vs nn.Sequential Use nn.Sequential for simple linear stacks of layers. Use nn.Module when you need custom forward logic, skip connections, or multiple input paths. Custom module is always more flexible.

        # 2. Forward pass

        # 3. Compute loss
        loss = criterion(predictions, y_batch)

        # 4. Backward pass (compute gradients)
        loss.backward()

        # 5. Update weights

    print(f"Epoch {epoch}: loss={loss.item():.4f}")

Master Interview Answers
🎤 Q: "What is a neural network and how does it learn?"
A neural network is a stack of layers where each layer transforms its input through learned weights and biases, followed by an activation function for non-linearity. It learns through backpropagation — computing the gradient of the loss with respect to every weight, then using an optimizer like Adam to nudge each weight in the direction that reduces the loss. This repeats for many epochs until the loss converges.
🎤 Q: "Why do we need activation functions?"
Without activation functions, stacking multiple linear layers still produces a single linear transformation — the network can only learn straight-line decision boundaries. Activation functions like ReLU introduce non-linearity, allowing the network to learn complex curved patterns. ReLU is the default for hidden layers because it's fast, avoids vanishing gradients, and works well in practice.
✅ One-line summary Neuron = weighted sum of inputs + bias, passed through activation. Layers: input → hidden(s) → output. ReLU for hidden layers. Sigmoid for binary output. Softmax for multi-class output. Training: forward pass → loss → backward pass → optimizer step. Repeat per epoch.
