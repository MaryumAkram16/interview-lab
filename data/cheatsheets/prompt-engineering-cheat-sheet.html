Prompt Anatomy
🎭 A system prompt is the director's brief to an actor. A user message is the scene. The better your brief, the better the performance. Vague instructions = unpredictable output. Precise instructions = consistent, reliable output.
The Four Components
ComponentPurpose
System PromptSet persona, constraints, output format, context
Few-shot ExamplesShow the model exactly what you want via examples
User MessageThe actual task or question
Context/DataDocuments, data, retrieved chunks to reason over
System Prompt — MediLens Example
SYSTEM PROMPT
You are a medical triage assistant for MediLens hospital platform. Your role is to assess patient symptoms and assign a triage priority level. Always respond in valid JSON with this structure: { "priority": "urgent|high|medium|low", "reason": "brief clinical justification", "recommended_action": "string" } Rules: - Never diagnose. Only triage. - If symptoms suggest emergency (chest pain, difficulty breathing), always set priority: "urgent" - Be concise. Max 2 sentences per field.

Prompting Patterns in Code
Few-Shot Prompting
import openai

client = openai.OpenAI()

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content":
            "Classify complaint severity: low/medium/high"},

        # Few-shot examples
        {"role": "user",      "content": "My order is late"},
        {"role": "assistant", "content": "low"},

        {"role": "user",      "content": "Wrong item sent"},
        {"role": "assistant", "content": "medium"},

        {"role": "user",      "content": "Charged twice, no refund"},
        {"role": "assistant", "content": "high"},

        # Actual task
        {"role": "user",      "content": "Package broken on arrival"},
    ]
)
Chain-of-Thought Prompting
CHAIN-OF-THOUGHT PATTERN
A patient reports: chest tightness, sweating, left arm pain, started 20 minutes ago. Think through this step by step: 1. What are the key symptoms? 2. Which conditions could cause these symptoms? 3. What is the urgency level and why? 4. What immediate action should be taken? Then give your final triage assessment.
JSON Output Forcing
# Force structured JSON output
response = client.chat.completions.create(
    model="gpt-4o",
    response_format={"type": "json_object"},
    messages=[{
        "role": "system",
        "content": "Return ONLY valid JSON. No prose."
    }, {
        "role": "user",
        "content": "Triage: headache for 3 days"
    }]
)
import json
result = json.loads(response.choices[0].message.content)

Master Interview Answers
🎤 Q: "What is prompt engineering and why does it matter?"
Prompt engineering is the practice of crafting inputs to LLMs to reliably produce the desired output. It matters because the same model can give wildly different results depending on how the prompt is structured. Techniques like few-shot examples, chain-of-thought reasoning, and explicit output formatting dramatically improve consistency. In my projects I use structured system prompts with JSON output constraints so n8n workflows can parse the AI response reliably every time.
✅ One-line summary Prompt = system prompt + examples + user message + context. Zero-shot = instruct only. Few-shot = show examples. Chain-of-thought = step-by-step reasoning. Temperature 0 = deterministic output (use for production). Force JSON output for structured pipelines.
