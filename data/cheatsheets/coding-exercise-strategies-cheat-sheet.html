Step 1 — Read the Problem Correctly

Before writing anything, answer these 4 questions in your head:

1
What is the INPUT? What type? What size? Can it be empty?
2
What is the OUTPUT? A number? A list? A boolean? A modified string?
3
What are the CONSTRAINTS? Sorted? Unique? Positive integers only?
4
What is the EDGE CASE? Empty input, one element, all duplicates, negative numbers?

Complete Solution Patterns
Pattern 1 — Two Sum (Hash Map)
def two_sum(nums, target):
    # Edge case first — always
    if not nums or len(nums) < 2:
        return []

    seen = {}  # num → index

    for i, num in enumerate(nums):
        complement = target - num

        if complement in seen:
            return [seen[complement], i]

        seen[num] = i

    return []  # no solution found

# Test it before submitting!
print(two_sum([2,7,11,15], 9))  # [0,1]
print(two_sum([], 5))            # []
Pattern 2 — Find Duplicates (Hash Set)
def find_duplicates(items):
    # Edge case
    if not items: return []

    seen = set()
    duplicates = []

    for item in items:
        if item in seen:
            duplicates.append(item)
        else:
            seen.add(item)

    return duplicates

# Test
print(find_duplicates([1,2,3,2,4,3]))
# [2, 3]
Pattern 3 — Most Frequent Item
from collections import Counter

def most_frequent(items):
    if not items: return None

    counts = Counter(items)
    return counts.most_common(1)[0][0]

print(most_frequent(['a','b','a','c','a']))
# 'a'
Pattern 4 — Group / Categorize Items
def group_by_length(words):
    if not words: return {}

    groups = {}

    for word in words:
        length = len(word)
        if length not in groups:
            groups[length] = []
        groups[length].append(word)

    return groups

# Or with setdefault (cleaner):
# groups.setdefault(length, []).append(word)

When You Get Stuck
Unstuck Ladder — Use in Order
1
Re-read the problem — you may have misread a constraint
2
Work a tiny example by hand — e.g. list of 2 items
3
Brute force first — get a working O(n²) before optimizing
4
Think data structures — would a dict / set / list help?
5
Talk through it — say what you're thinking out loud
