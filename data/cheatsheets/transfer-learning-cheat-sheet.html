What is Transfer Learning?
🎓 Transfer learning is like hiring a medical doctor to be a hospital administrator. They don't start from zero — they already understand medicine, human biology, and procedures. You just train them on the admin-specific parts. The pre-trained knowledge transfers to the new task.

A model pre-trained on a large dataset (e.g. ImageNet, all of Wikipedia) has already learned general features — edges, shapes, grammar, semantics. You reuse these features for your specific task instead of training from scratch.

PyTorch — Feature Extraction (Freeze All)
import torchvision.models as models
import torch.nn as nn

# Load pretrained ResNet
model = models.resnet18(pretrained=True)

# ✅ Freeze ALL layers
for param in model.parameters():
    param.requires_grad = False

# Replace final layer with your task's head
# ResNet18 has 512 features → your num_classes
num_classes = 4  # e.g. triage severity levels
model.fc = nn.Linear(512, num_classes)

# Now only model.fc has requires_grad=True
# Only the new head will be trained
PyTorch — Fine-Tuning (Unfreeze Last N Layers)
# Unfreeze last 2 layers only
for name, param in model.named_parameters():
    if "layer4" in name or "fc" in name:
        param.requires_grad = True
    else:
        param.requires_grad = False

# Use lower LR for fine-tuning
# Don't destroy the pretrained features!
optimizer = optim.Adam(
    filter(lambda p: p.requires_grad,
           model.parameters()),
    lr=1e-4   # much lower than training from scratch
)

Full Fine-Tuning with Transformers
from transformers import (
    AutoTokenizer,
    AutoModelForSequenceClassification,
    TrainingArguments, Trainer
)
from datasets import load_dataset

# 1. Load model + tokenizer
model_id = "distilbert-base-uncased"
tokenizer = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForSequenceClassification.from_pretrained(
    model_id, num_labels=2
)

# 2. Tokenize dataset
dataset = load_dataset("imdb")
def tokenize(batch):
    return tokenizer(batch["text"], truncation=True)
dataset = dataset.map(tokenize, batched=True)

# 3. Training config
args = TrainingArguments(
    output_dir="./results",
    num_train_epochs=3,
    per_device_train_batch_size=16,
    learning_rate=2e-5,         # low LR!
    evaluation_strategy="epoch"
)

# 4. Train
trainer = Trainer(
    model=model, args=args,
    train_dataset=dataset["train"],
    eval_dataset=dataset["test"]
)
trainer.train()
💡 Why lr=2e-5 for fine-tuning? Pre-trained weights encode years of training on billions of tokens. A high learning rate would catastrophically overwrite these features. Use 1e-5 to 5e-5 for fine-tuning transformers — 10–100x lower than training from scratch.
LoRA — Parameter-Efficient Fine-Tuning
🎯 LoRA is like adding sticky notes to a textbook instead of rewriting it. Instead of updating billions of weights, LoRA adds tiny learnable matrices to key layers. Only these small matrices train — 99% of the model stays frozen. Same quality, 100x cheaper.
from peft import get_peft_model, LoraConfig

# Configure LoRA

    r=16,              # rank — controls capacity
    lora_alpha=32,     # scaling factor
    target_modules=["q_proj", "v_proj"],
    lora_dropout=0.1,
    task_type="CAUSAL_LM"

Master Interview Answers
🎤 Q: "What is transfer learning and why is it useful?"
Transfer learning reuses a model pre-trained on a large dataset for a new, related task. Instead of training from scratch, you take all the general features the model already learned — edges in images, grammar in text — and adapt just the final layers to your specific task. This works well with small datasets where training from scratch would overfit, and it's dramatically faster and cheaper. All the LLMs I use in my projects — GPT-4o, Gemini — are examples of transfer learning applied at scale.
🎤 Q: "What is the difference between feature extraction and fine-tuning?"
Feature extraction freezes all pre-trained weights and only trains a new output head — the pre-trained model acts as a fixed feature extractor. Fine-tuning unfreezes some or all layers and trains them with a very small learning rate to adjust the features for the new domain. Feature extraction is faster and less prone to overfitting on small datasets. Fine-tuning gives better performance when you have enough data and the new domain differs from the pre-training domain.
✅ One-line summary Transfer learning = reuse pre-trained model instead of training from scratch. Feature extraction = freeze all, train new head only. Fine-tuning = unfreeze some layers, use low LR (1e-5). LoRA = train only tiny adapter matrices — 99% of model frozen. Always lower LR than scratch training.
